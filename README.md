## Usage

### Tmux

Launch `tmux` with `tx` alias

- To install plugins on first launch: `prefix` + `I`
- To update all plugins including `tpm` plugin manager: `prefix` + `U`

#### Tmux Keybindings

`<prefix>` key => `Ctrl` `a`

| key              | action                               |
| ------           | ------                               |
| `<prefix>` + `?` | Display a list of keyboard shortcuts |
| `<prefix>` + `r` | Reload tmux configuration |

### SwayWM

Launch `rofi` with `Super + Space`

#### Alacritty

Launch `alacritty` with `Super + Enter`
